# UTXO light client project

You can find README.md for each individual component in a dedicated directory.

./contract - smart contract to handle the state and proofs (Bitcoin, Dogecoin, Litecoin, Zcash variants)

./btc-types - shared header/block types

./merkle-tools - helper library with a set of merkle-tree utilities

The off-chain relayer lives in https://github.com/Near-One/btc-light-client-contract.
